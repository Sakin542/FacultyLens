## Out of scope (recorded, not implemented — spec §46)

* No API endpoint exists to create/edit live questions manually (questions enter through paper upload/extraction, approved AI generation and version restore). Validation on those paths is enforced (`gt:0` marks, enum lists, LO-in-course). A manual question CRUD would be a new feature.
* Inter-grader consistency: FacultyLens has a single grader of record per submission; no second-marker data model exists (unchanged from STEP 41).
